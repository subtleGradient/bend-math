# Starter casebook — planned, not executed

| Case | Input | Required behavior / falsifiable check |
| --- | --- | --- |
| Explicit happy path | TeX `1+1=2`, natural numbers stated | Primary Bend interpretation preserves Nat; Lean only if useful; proof status separate |
| Implicit invocation | "Make this PDF equation's claim precise" with visible definitions | Route to semantic transcription; preserve page locator and verify extraction visually |
| Bernoulli slice | Steady constant-density inviscid streamline statement | Inspect packages; useful Bend component and gap ledger; Real interpretation, scope and unencoded premises explicit; historical fixture not mistaken for finished output |
| Negative control | "Prove this already-precise theorem" | Hand off to proof workflow; do not call transcription a proof |
| Teaching boundary | "Tell a vortex story to explain these declarations" | Hand off teaching; no required story added to core output |
| Empirical boundary | "Does this prove the theory describes nature?" | Separate derivability from measurement and physical applicability |
| Ambiguous constant | Paper says `C` without specifying spatial scope | TODO for global vs streamline-specific constant; no silent choice |
| OCR trap | PDF superscript/subscript or minus sign extracted incorrectly | Check page or block unreadable expression; never fabricate |
| Target trap | Real equation, initially only F32 found | Expand package search with versioned evidence; generic/scoped useful Bend component where possible; abstract carrier not called Real; approximate companion only if requested |
| Ecosystem discovery | Catalog lists bignum and tensor packages | Distinguish catalogued/API-inspected/checked; inspect arithmetic, laws and Bend compatibility separately; no unsupported absence claim |
| Package preference | Supported package already provides needed algebra operations | Reuse inspected API rather than rebuilding local arithmetic or inventing package names |
| Gap acceptance | Needed tensor contraction law not covered by inspected API | Ledger states required operation/law, package/version evidence, workaround/dependency, minimal upstream API and testable law/domain acceptance criterion |
| Asymmetrical metric | Source specifies ordered two-slot form without symmetry | Faithful Bend component preserves order; no forced symmetric metric type, positive definiteness, inverse, or nondegeneracy; ask only for unresolved source laws |
| Default companion trap | Request asks only for Bend semantic transcription | No TypeScript output; Lean is supporting reference, not primary replacement |
| AST trap | Missing tensor abstraction tempts universal expression language | Bounded algebra/tensor component with explicit laws; no custom general-purpose AST or invented semantics |
| Quantifier trap | "For every streamline there exists C" | Do not translate as one C for all streamlines |
| Hole trap | Unknown density meaning vs missing conservation proof | Semantic ambiguity blocks statement; proof hole used only after statement fixed |
| Budget nightmare | 200-page paper, no chosen equation, many missing definitions | Select/ask for bounded slice; no whole-paper proof or invented glossary |
| Portability trap | Skill copied without original worktree or global skills | All live local references resolve; no reliance on unavailable global files |

Promotion requires observed outputs and review verdicts, not only this checklist.
